# Guía de uso · Alquimia Studio

Bienvenida a tu espacio de planners y lectura. Esta guía te acompaña para empezar y cuidar lo que guardes en la app.

## 1. Abrir y activar Alquimia Studio

1. Abre el enlace de Alquimia Studio o el archivo de inicio que recibiste.
2. Escribe el código de acceso incluido con tu compra y selecciona **Activar**.
3. La activación queda guardada en ese navegador. Si cambias de navegador o dispositivo, tendrás que volver a introducir el código.

Si tu navegador ofrece la opción **Instalar aplicación** o **Añadir a pantalla de inicio**, puedes usarla para abrir Alquimia Studio como una app. La opción depende del navegador y del dispositivo.

## 2. Explorar los planners

Elige un planner desde el menú lateral o desde las tarjetas de inicio. Puedes escribir en los campos, marcar opciones y volver a tus páginas cuando quieras: la información se guarda automáticamente en el navegador que estás usando.

En cada planner puedes usar **Imprimir / PDF** para imprimirlo o guardarlo como PDF desde las opciones de impresión del dispositivo. Si eliges **Borrar datos**, se elimina únicamente la información de ese planner en el navegador actual.

También puedes usar **Abrir archivo** para añadir un planner HTML compatible. Los archivos que añadas se guardan en este navegador.

## 3. Crear tu biblioteca de lectura

1. Abre **Mi Biblioteca**.
2. Pulsa **Subir PDFs** y elige uno o varios archivos PDF. También puedes arrastrarlos a la biblioteca desde un ordenador.
3. Selecciona una portada para abrir el lector.
4. Usa los controles para cambiar de página, acercar o alejar, ajustar el ancho, activar el modo noche o ver el libro a pantalla completa.
5. Marca la estrella para guardar un PDF en Favoritos. El lector recuerda la última página leída.

La biblioteca está pensada para leer y organizar PDFs. No modifica el contenido original del PDF ni añade anotaciones o texto sobre sus páginas.

## 4. Favoritos, búsqueda y apariencia

- Usa la estrella de un planner o PDF para agregarlo o quitarlo de **Favoritos**.
- La búsqueda del menú ayuda a encontrar planners; la búsqueda dentro de **Mi Biblioteca** encuentra PDFs por título.
- En el menú lateral, el botón de apariencia alterna entre **Modo oscuro** y **Modo claro**.

## 5. Guardar y recuperar una copia

Tus planners, PDFs y preferencias se guardan localmente en el navegador y dispositivo actuales. No hay una cuenta ni sincronización automática entre dispositivos. Si borras los datos del navegador, podrías perderlos.

Para conservar tu trabajo:

1. Abre el menú lateral y elige **Guardar una copia**.
2. Guarda el archivo `.json` en un lugar privado y seguro. Puede ocupar bastante espacio si contiene muchos PDFs.
3. Para recuperar tus datos, abre Alquimia Studio en el navegador donde quieras usarlos y selecciona **Restaurar una copia**.
4. Elige el archivo guardado y confirma. Los PDFs de la copia se agregarán o actualizarán; los demás PDFs de esa biblioteca se conservarán.

La copia incluye los datos guardados de los planners, tus preferencias, favoritos, PDFs y progreso de lectura. No incluye el código de acceso. Mantén el archivo privado: contiene tus documentos y datos personales.

## Si algo no funciona

- Si un PDF no se agrega, comprueba que sea un archivo PDF válido y vuelve a intentarlo.
- Si no ves tus datos, comprueba que estás usando el mismo navegador y dispositivo, o restaura tu copia.
- Si el código de acceso no funciona, revisa que lo hayas copiado completo y sin espacios adicionales.

Alquimia Studio no sube tus archivos a una cuenta en la nube: permanecen en el almacenamiento local de tu navegador, salvo que tú guardes o compartas una copia.
